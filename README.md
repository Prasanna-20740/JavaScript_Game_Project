# 🎮 JavaScript Guess The Number Game

A simple and interactive browser-based **Guess The Number Game** developed using HTML, CSS, and JavaScript.

The game generates a random number between 1 and 5. Players need to guess the correct number to win. Every incorrect guess reduces the player's score.

## 🚀 Project Overview

The Guess The Number Game is a beginner-friendly JavaScript project designed to demonstrate fundamental web development concepts and JavaScript programming logic.

Players enter a number, click the Check button, and receive instant feedback based on their guess.

## 🛠️ Tech Stack

- **Frontend:** HTML5
- **Styling:** CSS3
- **Programming Language:** JavaScript
- **DOM Manipulation:** JavaScript DOM
- **Version Control:** Git & GitHub

## ✨ Features

- Generates a random number between 1 and 5.
- Allows users to enter their guesses.
- Checks whether the entered number is correct.
- Displays instant feedback (Right or Wrong).
- Starts with a score of 10.
- Reduces the score by 1 for every incorrect guess.
- Displays a winning alert when the correct number is guessed.
- Simple and user-friendly interface.

## 🎯 How to Play

1. Open the game in your browser.
2. Enter a number between 1 and 5.
3. Click the **Check** button.
4. If your guess is correct, you win!
5. If your guess is incorrect, your score decreases by 1.
6. Try to guess the correct number before your score reaches zero.
